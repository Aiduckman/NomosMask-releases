# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer sees the report.

## What to include

- The NomosMask version (shown in the app) and your macOS version.
- A description of the problem and why you think it is a security issue.
- Steps to reproduce it, or a sample file that triggers it. Please do not send real personal data or real legal documents; use invented content.
- The impact as you see it (for example: a document that leaves the Mac, a file that crashes or exploits the app, a tampered update).

## What to expect

- An acknowledgement within 7 days.
- An assessment and a first answer within 30 days.
- A fix in a new release when the report is confirmed, and credit in the release notes if you wish.
- Please give us reasonable time to fix the problem before you publish details.

## Supported versions

Only the latest release is supported. Older releases are superseded and receive no fixes; please update to the latest release from the Releases page.

## Verifying downloads

See the section "Verifying a manual download" in the README and the `SHA256SUMS` file.
